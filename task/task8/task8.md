# Домашнее задание №8: Стратегии развёртывания

В этом задании вы примените различные стратегии для развёртывания собственного
приложения.

## Требования

1. Доработать приложение так, чтобы оно работало в нескольких подах
   (реплики ≥ 2): состояние вне пода, readiness/liveness-пробы, версия в ответе
   или метрике.
2. Запустить локально в minikube Envoy Gateway (Gateway API) по образцу из demo.
3. Обновить приложение, используя разные стратегии, и записать работу каждой
   (видео + логи):
   - **Rolling** — постепенное переключение на новые реплики.
   - **Blue/Green** — мгновенное переключение и откат.
   - **Canary** — ramp 90/10 → 50/50 → 0/100.
   - **A/B** — по заголовку на выбранную аудиторию.
   - **Shadow** — зеркалирование копии трафика.

## Критерии оценки

| Пункт | Баллы |
|-------|-------|
| Реализованы и продемонстрированы все стратегии | 10 |
| Отсутствие какой-либо из описанных стратегий | −2 за каждую |
