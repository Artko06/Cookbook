# Домашнее задание №7: Дашборды в Grafana

К этому моменту курса у вас уже есть приложение с настроенным экспортом метрик в
Victoria Metrics в рамках домашнего задания №4 (метрики), а также реализован
подсчёт SLA в домашнем задании №5 (SLI / SLO / SLA).

В этом задании вы построите в Grafana дашборд, который собирает всё это в единую
картину.

## Требования

1. Запустить Grafana в minikube любым удобным способом. Например, по инструкции:

   ```bash
   helm repo add grafana-community https://grafana-community.github.io/helm-charts
   helm repo update
   helm install grafana grafana-community/grafana --namespace monitoring
   # пробросить порт
   kubectl port-forward svc/grafana 3000:80 -n monitoring
   ```

2. Добавить data source Victoria Metrics в Grafana.
3. Создать панели с отображением состояния приложения: верхнеуровневые метрики
   (статусы, RPS, ошибки) и детализация (метрики рантайма). Вспомните подходы
   RED, USE и Golden Signals.
4. Вывести подсчёт SLA пробера в отдельную панель.
5. Импортировать дашборд PostgreSQL Exporter и показать его работу.

## Артефакты

- Экспортированный JSON дашборда приложения в Grafana.
- Файл **`Отчёт.md`** со скриншотами панелей и коротким описанием: какие панели и
  метрики выбраны и почему, какие источники данных использованы.
- Короткий скринкаст с демонстрацией дашбордов (включая импортированный дашборд
  PostgreSQL).
