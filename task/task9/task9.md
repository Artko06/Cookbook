# Домашнее задание №9: Балансировка трафика с Gateway API

В рамках данного задания вам необходимо развернуть две версии своего приложения
(из предыдущих домашних заданий) в Kubernetes и настроить распределение
HTTP-трафика между ними с помощью Gateway API.

## Требования

1. Развернуть две версии приложения (v1 и v2) в minikube.
2. Создать отдельный ClusterIP Service для каждой версии.
3. Настроить Gateway и HTTPRoute с распределением трафика: 90% на v1 и 10% на v2.
4. Отправить 100–200 запросов и проверить фактическое распределение между
   версиями.

## Артефакты

- YAML-манифесты Deployment, Service, Gateway и HTTPRoute.
- Результаты отправки 100–200 запросов с количеством ответов от каждой версии.
- Краткий вывод о фактическом распределении трафика и его соответствии заданным
  весам 90/10.
- Файл **`Отчёт.md`**, включающий всё вышеперечисленное.

## Критерии оценки

| Пункт | Баллы |
|-------|-------|
| Развёрнуты две версии приложения и созданы отдельные ClusterIP Service | 3 |
| Настроены Gateway и HTTPRoute с весами 90/10 | 4 |
| Проведена проверка распределения трафика и представлен вывод по результатам | 3 |
