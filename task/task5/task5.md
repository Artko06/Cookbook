# Домашнее задание №5: SLI, SLO и SLA

Существуют два основных подхода для подсчёта доступности при помощи SLI:

- **TBSLO (Time Based SLO)** — подсчёт соотношения «хороших» и «плохих» минут
  работы сервиса на основании совокупности SLI.
- **RBSLO (Request Based SLO)** — подсчёт соотношения успешных и неуспешных
  операций.

В рамках данного задания вам необходимо на базе собранных в прошлом домашнем
задании метрик сформулировать и отобразить SLI, SLO и SLA для своего приложения.

## Требования

1. Выбрать минимум 3 метрики, реализованные в прошлом домашнем задании, которые
   будут использоваться в качестве SLI, реализовать пробер.
2. Сформулировать для них SLO.
3. Сформулировать SLA для приложения. Опционально сформулировать общий SLA для
   всего набора SLO.
4. Отобразить графики индикаторов.

## Артефакты

- В качестве решения приложите архив с файлом **`Отчёт.md`** и скринкастом с
  демонстрацией графиков.
- В отчёте должны быть:
  - Описания выбранных метрик.
  - Формулировки SLI, SLO и SLA и формулы их расчёта.
  - Описание изменений приложения для скринкаста.
- На скринкасте должна быть демонстрация изменения метрик и графиков SLI, SLO и
  SLA в результате изменения поведения приложения.
- Для демонстрации можно использовать **vmui**, уже установленный вами в составе
  чарта Victoria Metrics, либо **Grafana** (опционально, подробно рассматривать
  данный инструмент будем на следующих семинарах).
- Опционально можно добавить в архив скриншоты графиков.
